# Nuctracker Pipeline: Datawrapper

After you have run the model and updated datawrapper, it is important to make sure the graphs are updated properly

Step 1: DO NOT EXIT OUT OF THE TERMINAL

Step 2: Go to https://app.datawrapper.de/uraClWBtNi/archive/391964. Here is where the Nuctracker part of datawrapper is stored

Step 3: There are three graphs: Nuclear Availability and Production (contains a line graph of Availabilities and Production); Avg French Nuclear Availability (contains a table with the average availabilities and trends); and Nuclear Production (Realized and Forecasted) (contains a table of the realized and forecasted production)

Step 4: Make sure each graph is properly formatted. After editing, make sure to Publish and Embed
- The Nuclear Availability and Production graph needs to have all the line titles in the legend instead of on the side, which can be edited by going into the edit options, Visualize, Refine, Customize Lines, clicking on the line that is improperly formatted, then selecting As Legend and unselecting Next to Line.
- Avg French Nuclear Availability needs to only contain data from the current month on, which is done by going into the edit options, going to Upload Data, and simply deleting all rows before the current month.
- Nuclear Production (Realized and Forecasted) needs the output obtained from the terminal, since it is the only table not updated automatically. At the end of the terminal output after running the model, there will be a table containing the data needed to replace in the Datawrapper table. Simply copy and paste the output into the Datawrapper table by going into the Edit option, Check and Describe, and replacing the relevant data. Remember to also change the dates of the column names.
